# XCSoar Blitzeinstieg

## XCSoar Einrichten

Nach dem Herunterladen der entsprechenden Programmversion (Android, PC, Linux, Mac) sollte diese in ein entsprechendes Verzeichnis entpackt bzw. installiert werden.

Je nach Betriebssystem sollte ein Verzeichnis gewählt werden, welches vollen Zugriff hat. Es ist zwingend ein Unterverzeichnis `XCSoarData` zu erstellen, in dem sämtliche Konfigurationsfiles, Luftraumfiles, Wegpunktfiles und das XCM-Terrain/Geländefile untergebracht wird.

Die Installationsroutinen von Android, Windows Mobile, PPC, PC machen dies von alleine. Betrieb von SD-Karte ist möglich. Andere Verzeichnisse sind möglich, aber die Standardstruktur wird empfohlen.

### Schritte

1. Download von der Homepage
2. XCM File laden
3. Wegpunkte laden (CUP oder OpenAir Format)
4. Luftraumfile laden:  
   https://www.daec.de/fachbereiche/luftraum-flugbetrieb/luftraumdaten
5. Dateien in `XCSoarData` ablegen

Wichtig: Alle Dateien müssen in `/XCSoarData` liegen.

## Dateimanager

Achtung: Der Dateimanager funktioniert unter Android erst ab Android 2.2.

Mit dem integrierten Dateimanager können fehlende Dateien direkt heruntergeladen werden:

- Menü: Konfig → Datei Manager → Hinzufügen
- Dateien auswählen und downloaden

Beispiele:
- `Thermal_Spaces_EU.txt`
- `OpenAIP-Hotspots.cup`

Konfig → Aussehen → Sprache, Eingabe

## Wegpunkte

### Flugplatz wählen

1. Klick auf Karte
2. Flugplatz auswählen
3. „Ziele auf“ drücken

### Heimatflugplatz setzen

1. Klick auf Flugplatz
2. Details öffnen
3. „Setze als neuer Heimatort“

## Aufgaben / Wettbewerb

### Aufgabe erstellen

Navigation:

Aufgabe → Verwalten → Neue Aufgabe

- Regeln einstellen
- Wendepunkte hinzufügen
- Aufgabe speichern

### Aufgabe starten

- Aufgabe speichern
- „Fliegen“ auswählen
- Startlinie überfliegen

XCSoar zeigt:
- Sektoren
- Abflugpunkt
- Navigation zum Start

### AAT Aufgaben

Optimierungsmodus beeinflusst Kursberechnung.

- „Optimiert“ EIN → automatische Optimierung
- AUS → manuelles Verschieben

## Generell (wichtige Hinweise)

- XCSoar kennt zwei Modi: Aufgabe und freies Fliegen
- Berechnungen basieren auf kompletter Aufgabe (nicht nur nächster Punkt)
- MC-Wert beeinflusst alle Berechnungen
- Endanflug basiert auf reinem Gleiten (MC = 0)
- Wind kann Endanflug stark beeinflussen
- Infoboxen können Aufgaben- und Wegpunktdaten gleichzeitig anzeigen
