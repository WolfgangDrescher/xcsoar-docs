Data files used by XCSoar fall into two categories:

- **Flight data files**  
  These files contain data relating to the aircraft type, airspace and maps,
  waypoints, etc. These are the files that are most likely to be modified or set
  by normal users.

- **Program data files**  
  These files contain data relating to the "look and feel" of the program,
  button assignments, and input events.

This chapter focuses on flight data files; see the *XCSoar Advanced
Configuration Guide* for details on program data files.
