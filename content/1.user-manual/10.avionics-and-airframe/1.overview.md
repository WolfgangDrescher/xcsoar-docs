This chapter provides instructions for using XCSoar in typical cross-country
tasks.  It is separated into simple scenarios to demonstrate how to use key
features.  It assumes the configuration options have already been set up to the
user's preferences.

These instructions are intended to provide a simple step-by-step guide to flying
tasks of varying levels of complexity but are not intended to demonstrate all
the features of XCSoar.  Furthermore, the system can be used productively in
ways other than as described here.
